# 简谱文本格式

程序把识别出来的简谱存成下面这种纯文本，你可以在网页里直接修改它。

## 头部（写在第一个声部之前，都可以省略）

```
标题: 大鱼
调号: 1=G
拍号: 4/4
速度: 72
顺序: A B A C D
```

- `调号`：`1=C`、`1=G`、`1=bB`（降B）、`1=#F`（升F）。
- `速度`：每分钟四分音符的拍数。
- `顺序`：演奏顺序，配合段落标记 `$A`、`$B` 使用；不写就按段落出现的先后各演奏一遍。

## 声部

单独一行 `[声部名]` 开始一个声部，后面的行都属于它，直到下一个 `[...]`。
同一个声部可以写很多行，程序会按顺序接起来。所有声部从同一时刻开始，一起演奏。

```
[笛子]
1 2 3 5 | 6 - - 0 |
[琵琶]
<1 5> - <3 5> - | 6, - - 0 |
```

## 音符

| 写法 | 含义 |
|---|---|
| `1`–`7` | 音级 do re mi fa sol la si |
| `0` | 休止 |
| `#4`、`b7` | 升、降（写在数字前面） |
| `1'`、`1''` | 高一个、两个八度（数字上面的点） |
| `6,`、`6,,` | 低一个、两个八度（数字下面的点） |
| `3_` | 一条减时线（八分音符） |
| `3__` | 两条减时线（十六分音符） |
| `3___` | 三条减时线（三十二分音符） |
| `5.`、`5_.` | 附点 |
| `-` | 增时线，单独写，把前一个音延长一拍 |
| `5~` 或单独的 `~` | 延音线：和下一个相同的音连成一个音 |
| `<1 3 5>` | 和弦（竖着叠在一起的音），后面可以接 `_` `.` `~` |
| `(3 1_ 2_ 3_)` | 三连音（`(5 ...)` 五连音、`(6 ...)` 六连音同理）。括号后面紧跟数字再加空格才是连音；别处的括号会被忽略 |

后缀的顺序随意：`6,_`、`6_,` 都可以。

## 小节线和反复

| 写法 | 含义 |
|---|---|
| `\|` | 小节线 |
| `\|\|` 或 `\|]` | 双纵线、终止线 |
| `\|:` … `:\|` | 反复记号，中间的部分演奏两遍 |

## 段中变化和段落

| 写法 | 含义 |
|---|---|
| `@2/4` | 从这里起改拍号 |
| `@1=F` | 从这里起改调（只影响本声部） |
| `@q=60` | 从这里起改速度（影响所有声部） |
| `$A` | 段落标记 A（配合头部的 `顺序`） |
| `// ...` | 注释，到行尾 |

某个声部在某个段落里没有音符时，程序会自动用休止补齐，所以各声部始终对齐。

## 力度

写在音符之间，从这里起生效，只影响本声部。

| 写法 | 含义 |
|---|---|
| `@ppp` `@pp` `@p` `@mp` `@mf` `@f` `@ff` `@fff` | 力度（不写时按 mf） |
| `@<` … `@f` | 渐强，到后面那个力度为止 |
| `@>` … `@p` | 渐弱，到后面那个力度为止 |
| `@<` … `@!` | 渐强（或渐弱）没有写终点力度，用 `@!` 表示结束 |
| `@sf`、`@sfz` | 下一个音突强 |
| `@fp` | 下一个音强，之后马上弱（p） |

## 演奏记号

写在音符（或和弦）后面，可以叠加，比如 `5_!tr`、`6!^`、`<1 5>!^`。

| 写法 | 含义 |
|---|---|
| `!^` | 延长记号（这段时间所有声部一起放慢） |
| `!>` | 重音 |
| `!tr` | 颤音（主音和上方音快速交替） |
| `!w` | 波音（上波音：主音—上方音—主音） |
| `!lw` | 下波音（主音—下方音—主音） |
| `!/` | 上滑音（从下面滑进这个音） |
| `!\` | 下滑音（音尾往下滑） |
| `!o` | 泛音 |
| `!arp` | 琶音（和弦前的竖波浪线，和弦里的音从低到高依次奏出），例如 `<5, 7, 2 5>!arp` |
| `{6}5`、`{1' 7}6` | 倚音：花括号里是前面的小音符，紧贴在主音前写 |

歌词、指法、弓法、换气记号不写。
